# Windows 로또 베이지안 번호 추천

**[Windows 프로그램 다운로드 (EXE 포함 ZIP)](https://github.com/21227386/lotto/raw/refs/heads/main/downloads/LottoBayes_Windows_x64.zip)** · [엑셀 입력 양식](https://github.com/21227386/lotto/raw/refs/heads/main/downloads/lotto_input_template.xlsx)

다운로드한 ZIP을 풀고 `Lotto Generator.exe`를 실행하세요. Python 설치나 배치 파일 실행이 필요 없습니다. ZIP에는 빈 엑셀 입력 양식과 사용 설명서가 포함됩니다.

검증: 모델·엑셀 테스트 11개 통과. Wine 10에서 Windows Python GUI의 엑셀 읽기·추천·저장을 확인하고, 배포 EXE의 창 실행·정상 종료를 확인했습니다. 실제 Windows PC에서의 검증은 아직 수행하지 않았습니다.

첨부 형식인 **Draw / Draw date / N1~N6 엑셀(.xlsx)** 파일에서 최근 412회 본번호를 읽고 베이지안 추정과 가중 비복원추출로 다음 회차 추천 번호 6개를 생성하는 한국어 GUI입니다.

## Windows 사용 방법

1. 배포 ZIP을 풀고 `Lotto Generator.exe`를 더블 클릭합니다. Python이나 Excel 설치 없이 실행됩니다.
2. **입력용 엑셀 양식 저장**을 눌러 양식을 만들거나 함께 제공된 `lotto_input_template.xlsx`를 엽니다.
3. 헤더 아래에 최소 412회 데이터를 입력하고 `.xlsx`로 저장합니다. 기존 `Donghaeng_Lotto.xlsx`도 바로 사용할 수 있습니다.
4. **엑셀 파일 열기 (.xlsx)** → **분석 후 6개 추출**을 누릅니다.
5. **추천 번호·분석 결과 엑셀 저장**으로 추천 조합, 대상 회차, 설정, 번호별 추정값을 저장할 수 있습니다.

대상은 Windows 10/11 64비트(x64)입니다. 배포 EXE에는 Python, Tk, openpyxl이 포함됩니다. 전자서명은 적용하지 않았습니다.

## 엑셀 입력 형식

`Lotto Draws` 시트가 있으면 해당 시트를 읽고, 없으면 활성 시트를 읽습니다. 첨부된 `Donghaeng_Lotto.xlsx`와 같은 아래 8열 형식을 사용하세요.

| Draw | Draw date | N1 | N2 | N3 | N4 | N5 | N6 |
|---|---|---|---|---|---|---|---|
| 회차 | 추첨일 | 본번호1 | 본번호2 | 본번호3 | 본번호4 | 본번호5 | 본번호6 |

- 첫 행의 헤더는 `Draw`, `Draw date`, `N1`, `N2`, `N3`, `N4`, `N5`, `N6`입니다. 대소문자는 구분하지 않습니다.
- 매주 파일 맨 아래에 새 회차, 실제 추첨일, 실제 본번호 6개를 추가하고 저장한 후 프로그램에서 다시 여세요. 프로그램은 원본 파일을 수정하지 않습니다.
- 오래된 행을 지울 필요가 없습니다. 회차 기준으로 정렬해 **최근 412회**를 자동 선택합니다. 파일의 행 순서는 무관합니다.
- 예: 836~1247회 입력 → 1248회 추천. 1248회를 추가하면 837~1248회 분석 → 1249회 추천.
- GUI에서 전체 회차 수, 실제 분석 범위, 추천 대상 회차 및 다음 추첨 예정일(최신 입력 추첨일 + 7일)을 확인할 수 있습니다. 다음 추첨 예정일은 입력값 기반이며 공식 일정 조회 결과가 아닙니다.
- 날짜는 Excel 날짜 셀이나 `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD` 텍스트를 지원합니다. 번호 분석은 회차별 본번호만 사용합니다.
- 회차 중복, 최근 412회 내 회차 누락, 추첨일 역전·중복, 1~45 범위를 벗어난 번호, 회차 내 번호 중복, 빈 셀, 수식을 검사합니다.
- 보너스 번호와 추가 열은 제외하세요. 최소 412회가 필요합니다. 날짜를 포함한 8열 형식은 헤더가 필수입니다.
- 이전 버전의 회차 + 본번호 6개(7열) 형식도 지원합니다. 회차 없는 본번호 6열 입력은 정확히 412회만 허용하며 추첨일은 표시하지 않습니다.
- `.xls`와 암호화 파일은 지원하지 않습니다. `.xlsx`로 저장하세요.

배포 양식에는 실제 데이터가 없습니다. 첨부 파일은 호환성을 확인하는 데 사용했으며 저장소에 포함하지 않았습니다. GUI 상단의 Lotto 이미지는 EXE에 내장되어 별도 이미지 파일 없이 표시됩니다.

## 확률 모델

번호 i의 회차별 포함확률을 p_i라고 할 때 사전분포는 `Beta(s × 6/45, s × 39/45)`입니다. 사전 강도 s의 기본값 412는 균등 확률을 갖는 가상 412회를 의미하며 데이터로 최적화한 값이 아닙니다. s가 클수록 균등 기준으로 강하게 보정합니다.

N=412회 중 c_i회 출현했다면 사후분포는 `Beta(s × 6/45 + c_i, s × 39/45 + N − c_i)`이며 사후 평균은 `(s × 6/45 + c_i)/(s+N)`입니다. 표준편차는 해당 Beta 분포의 표준편차입니다. 균등 대비 차이는 퍼센트포인트로 표시합니다.

기본 추출은 사후 평균을 가중치로 사용합니다. 매 단계 남아 있는 번호 중 `w_i / sum(w_remaining)` 확률로 하나를 뽑고 그 번호를 제거하는 순차 가중 비복원추출(Plackett–Luce)입니다. 체크박스를 켜면 매 추천마다 각 Beta 사후분포에서 가중치를 추출해 불확실성도 반영합니다. 결과는 표시할 때만 오름차순으로 정렬합니다. 결과 엑셀에는 추천 조합, 분석 범위, 최신·다음 추첨일, 파일 전체 회차 수 및 45개 번호의 분석값을 저장합니다.

번호별 Beta–Binomial은 주변 포함확률에 대한 모델입니다. 한 회차에서 반드시 6개를 고르므로 번호 간 관측은 독립이 아닙니다. 여기서는 독립 사후근사를 사용하며 정확한 6개 부분집합 우도에 대한 베이지안 결합추론은 하지 않습니다. **추출에 사용한 가중치와 최종 6개 중 포함될 확률은 다릅니다.** 이는 단순 출현빈도 순위 선정과 달리 균등 기준 보정과 무작위 비복원추출을 반영하지만, 당첨 예측력이 입증된 모델은 아닙니다.

공정하고 독립적인 추첨에서는 모든 조합의 1등 확률이 1/8,145,060입니다. 과거의 미출현이나 고빈도가 미래 당첨 우위를 보장하지 않습니다. 실제 과거 데이터로 성능 백테스트를 수행하지 않았습니다.

## 개발 및 검증

소스에서 실행할 때는 Python 3.10 이상과 Tcl/Tk가 필요합니다.

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python lotto_gui.py
```

Windows 개발자가 EXE를 재빌드할 때:

```text
python -m pip install -r requirements-build.txt
python build_exe.py
```

결과는 `dist/Lotto Generator.exe`입니다. 사용자는 빌드나 배치 파일 실행이 필요 없습니다.

모델 및 엑셀 테스트는 합성 데이터로 입력 검사, 사후 갱신식, 균등 기준 보정, 가중치 효과, 중복 없는 추출, 결과 엑셀 재열기를 확인합니다. 실제 당첨 데이터 성능 백테스트는 수행하지 않았습니다. 데이터는 로컬에서만 처리하고 네트워크로 보내지 않습니다.
