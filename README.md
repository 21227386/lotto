# Lotto Generator

**[Windows 프로그램 다운로드 (EXE 포함 ZIP)](https://github.com/21227386/lotto/raw/refs/heads/main/downloads/LottoBayes_Windows_x64.zip)** · [엑셀 입력 양식](https://github.com/21227386/lotto/raw/refs/heads/main/downloads/lotto_input_template.xlsx)

ZIP을 풀고 `Lotto Generator.exe`를 실행하세요. Windows 10/11 x64 대상이며 Python이나 Excel을 설치할 필요가 없습니다. EXE에는 Python, Tk, openpyxl과 상단 Lotto 이미지가 포함됩니다. 전자서명은 적용하지 않았습니다.

## 사용 방법

1. 기존 `Donghaeng_Lotto.xlsx` 또는 포함된 빈 양식에 최소 412회의 데이터를 준비합니다.
2. **Select Input File**로 `.xlsx` 파일을 선택합니다.
3. **분석 후 5세트 추출**을 누르면 모델 기준 상위 5개 조합을 표시합니다.
4. **추천 5세트 엑셀 저장**으로 추천 번호와 분석 범위·대상 회차를 저장할 수 있습니다.
5. 다음 주에는 새 회차의 Draw, Draw date, 본번호 6개를 행으로 추가해 저장한 후 파일을 다시 선택하세요.

파일에 들어 있는 **모든 회차**를 분석합니다. 836~1247회(412회)에서 1248회를 추가하면 **836~1248회 전체 413회**로 1249회를 추천합니다. 오래된 데이터를 지우거나 고정 길이로 자르지 않습니다.

같은 데이터와 설정에서는 버튼을 반복해서 눌러도 **동일한 5세트**를 표시합니다. 각 세트는 중복 없는 6개 번호이며, 5세트는 서로 다른 조합입니다. 세트 사이에는 번호가 겹칠 수 있습니다. 데이터가 추가되더라도 순위가 유지되면 추천이 같을 수 있습니다.

GUI 제목은 `Lotto Generator`이며 입력 원본 표와 번호별 통계 표는 표시하지 않습니다. 선택 파일명, 간단한 처리 상태, 추천 5세트만 보여줍니다.

## 엑셀 입력 형식

`Lotto Draws` 시트가 있으면 해당 시트를 읽고, 없으면 활성 시트를 읽습니다. 아래 8열 형식을 권장합니다.

| Draw | Draw date | N1 | N2 | N3 | N4 | N5 | N6 |
|---|---|---|---|---|---|---|---|
| 회차 | 추첨일 | 본번호1 | 본번호2 | 본번호3 | 본번호4 | 본번호5 | 본번호6 |

헤더 대소문자는 구분하지 않습니다. 번호는 정수 셀로 입력하고 보너스 번호·추가 열·수식은 제외하세요. 날짜는 Excel 날짜 셀이나 `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD` 텍스트를 지원합니다.

입력 데이터 전체의 회차 중복·누락, 추첨일 순서, 번호 범위(1~45), 회차 내 번호 중복, 빈 셀 등을 검사합니다. 행 순서는 무관하며 회차 기준으로 정렬합니다. 최소 412회가 필요합니다. 이전 7열(회차 + 본번호)과 6열(본번호만) 입력도 전체 행을 사용하지만, 누락된 회차·날짜 정보는 표시할 수 없습니다.

다음 대상 회차는 입력의 최대 회차 + 1이며 추첨 예정일은 최신 입력 날짜 + 7일입니다. 공식 일정 자동 조회는 하지 않습니다. 원본 엑셀 파일은 수정하지 않으며 데이터는 외부로 전송하지 않습니다. `.xls`와 암호화 파일은 지원하지 않습니다. 첨부된 원본 데이터는 배포하지 않습니다.

## 모델과 5개 조합의 순위

번호 i의 포함확률에 `Beta(s × 6/45, s × 39/45)` 사전분포를 둡니다. 사전 강도 s는 412로 고정하며 가상의 균등 추첨 412회를 의미합니다. **이 값은 실제 분석 회차 수의 제한이 아닙니다.**

입력의 전체 N회 중 c_i회 출현했다면 사후 평균 가중치는 `(s × 6/45 + c_i)/(s + N)`입니다. 전체 행이 N과 출현 횟수에 반영됩니다. 번호별 Beta–Binomial은 주변확률 추정이며 번호 간 독립 사후근사를 사용합니다.

이 가중치를 이용해 번호를 한 번씩 제거하는 순차 가중 비복원추출(Plackett–Luce) 모델을 정의합니다. 실제로 무작위 재추출하지 않고, 각 6개 조합의 720가지 선택 순서 확률을 부분집합 동적계획법으로 합산합니다. 가중치 순위에 대한 단조성을 이용한 우선순위 탐색으로 **모델 조합 확률이 높은 서로 다른 5개 조합**을 결정적으로 선택합니다. 사후 가중치 샘플링과 무작위 다양화는 사용하지 않습니다.

이 순위는 적합된 추천 모델 내부의 순위이며 실제 당첨 확률 우위를 입증하지 않습니다. 공정하고 독립적인 로또에서는 모든 조합의 1등 확률이 1/8,145,060입니다. 과거 결과를 이용한 모델 성능 백테스트는 수행하지 않았습니다.

## 개발 및 검증

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python lotto_gui.py
```

Windows에서 재빌드:

```text
python -m pip install -r requirements-build.txt
python build_exe.py
```

결과는 `dist/Lotto Generator.exe`입니다. 소스 실행에는 Python 3.10 이상과 Tcl/Tk가 필요합니다.

모델·엑셀 테스트 15개가 통과했습니다. 전체 413회 반영, 재현성, 중복 없는 5개 조합, 부분집합 확률과 720개 순서 확률의 일치, 작은 후보군 전수 계산과 상위 5개 순위의 일치 등을 확인합니다. Wine 10에서 Windows Python GUI의 파일 읽기·추천·저장과 배포 EXE의 창 실행·정상 종료를 검증합니다. 실제 Windows PC에서의 검증은 아직 수행하지 않았습니다.
