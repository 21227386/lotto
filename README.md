## Windows 사용 방법

1. 배포 ZIP을 풀고 `LottoBayes.exe`를 더블 클릭합니다. Python이나 Excel 설치 없이 실행됩니다.
2. **입력용 엑셀 양식 저장**을 눌러 양식을 만들거나 함께 제공된 `lotto_input_template.xlsx`를 엽니다.
3. 헤더 아래에 최근 412회 데이터를 입력하고 `.xlsx`로 저장합니다.
4. **엑셀 파일 열기 (.xlsx)** → **분석 후 6개 추출**을 누릅니다.
5. **추천 번호·분석 결과 엑셀 저장**으로 추천 조합, 대상 회차, 설정, 번호별 추정값을 저장할 수 있습니다.

대상은 Windows 10/11 64비트(x64)입니다. 배포 EXE에는 Python, Tk, openpyxl이 포함됩니다. 전자서명은 적용하지 않았습니다.

## 엑셀 입력 형식

활성 시트(Excel에서 마지막으로 선택한 시트)를 읽습니다. 한 행에 **회차 + 본번호 6개**, 총 7열을 권장합니다.

| 회차 | 번호1 | 번호2 | 번호3 | 번호4 | 번호5 | 번호6 |
|---|---|---|---|---|---|---|
| 836 | 1 | 9 | 11 | 14 | 26 | 28 |

위 숫자는 **형식 설명용이며 실제 당첨 데이터가 아닙니다**. 배포 양식에는 실제 데이터가 없습니다. 사용자가 공식 당첨 결과를 확인해 412개 행을 채워야 합니다.

- 숫자는 정수 셀로 입력하세요. 수식, 날짜, 문자열, 보너스 번호 열은 제외합니다.
- 본번호 6개만 입력하는 6열 형식도 지원합니다. 이 경우 회차와 최신성은 확인할 수 없습니다.
- 헤더는 선택사항이며 `회차,번호1,...,번호6` 또는 `draw,n1,...,n6`를 사용합니다. 6열 입력은 회차 헤더를 생략합니다.
- 회차가 있으면 연속성과 중복을 검사합니다. 행 순서는 무관합니다. 빈 행은 무시합니다.
- 정확히 412회, 본번호 1~45, 한 회차에 서로 다른 6개 번호가 필요합니다.
- `.xls`는 지원하지 않습니다. Excel이나 LibreOffice에서 `.xlsx`로 저장하세요. 암호화 파일은 지원하지 않습니다.
- **7열을 본번호 6개 + 보너스 번호로 사용하지 마세요.** 7열의 첫 열은 회차입니다.
- 836~1247회 입력은 1248회를 대상으로 합니다. 실제 차주를 추천하려면 최신 412회를 입력하세요.

## 확률 모델

번호 i의 회차별 포함확률을 p_i라고 할 때 사전분포는 `Beta(s × 6/45, s × 39/45)`입니다. 사전 강도 s의 기본값 412는 균등 확률을 갖는 가상 412회를 의미하며 데이터로 최적화한 값이 아닙니다. s가 클수록 균등 기준으로 강하게 보정합니다.

N=412회 중 c_i회 출현했다면 사후분포는 `Beta(s × 6/45 + c_i, s × 39/45 + N − c_i)`이며 사후 평균은 `(s × 6/45 + c_i)/(s+N)`입니다. 표준편차는 해당 Beta 분포의 표준편차입니다. 균등 대비 차이는 퍼센트포인트로 표시합니다.

기본 추출은 사후 평균을 가중치로 사용합니다. 매 단계 남아 있는 번호 중 `w_i / sum(w_remaining)` 확률로 하나를 뽑고 그 번호를 제거하는 순차 가중 비복원추출(Plackett–Luce)입니다. 체크박스를 켜면 매 추천마다 각 Beta 사후분포에서 가중치를 추출해 불확실성도 반영합니다. 결과는 표시할 때만 오름차순으로 정렬합니다. 결과 엑셀에는 추천 조합과 45개 번호의 분석값을 저장합니다.

번호별 Beta–Binomial은 주변 포함확률에 대한 모델입니다. 한 회차에서 반드시 6개를 고르므로 번호 간 관측은 독립이 아닙니다. 여기서는 독립 사후근사를 사용하며 정확한 6개 부분집합 우도에 대한 베이지안 결합추론은 하지 않습니다. **추출에 사용한 가중치와 최종 6개 중 포함될 확률은 다릅니다.** 이는 단순 출현빈도 순위 선정과 달리 균등 기준 보정과 무작위 비복원추출을 반영하지만, 당첨 예측력이 입증된 모델은 아닙니다.

공정하고 독립적인 추첨에서는 모든 조합의 1등 확률이 1/8,145,060입니다. 과거의 미출현이나 고빈도가 미래 당첨 우위를 보장하지 않습니다. 실제 과거 데이터로 성능 백테스트를 수행하지 않았습니다.

## 개발 및 검증

소스에서 실행할 때는 Python 3.10 이상과 Tcl/Tk가 필요합니다.

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python lotto_gui.py
```

Windows 개발자가 EXE를 재빌드할 때:

```text
python -m pip install -r requirements-build.txt
python build_exe.py
```

결과는 `dist/LottoBayes.exe`입니다. 사용자는 빌드나 배치 파일 실행이 필요 없습니다.

모델 및 엑셀 테스트는 합성 데이터로 입력 검사, 사후 갱신식, 균등 기준 보정, 가중치 효과, 중복 없는 추출, 결과 엑셀 재열기를 확인합니다. 실제 당첨 데이터 성능 백테스트는 수행하지 않았습니다. 데이터는 로컬에서만 처리하고 네트워크로 보내지 않습니다.
