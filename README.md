# Lotto Generator

**[Windows 프로그램 다운로드 (EXE 포함 ZIP)](https://github.com/21227386/lotto/raw/refs/heads/main/downloads/LottoBayes_Windows_x64.zip)** · [엑셀 입력 양식](https://github.com/21227386/lotto/raw/refs/heads/main/downloads/lotto_input_template.xlsx)

별도 1248회 고정 데이터·5세트·2회 실행 제한 버전은 [One-time Lotto Generator for You](ONE_TIME_README.md)를 참고하세요. 일반 프로그램 다운로드는 기존 파일 그대로입니다.

ZIP을 풀고 `Lotto Generator.exe`를 실행하세요. Windows 10/11 x64 대상이며 Python이나 Excel을 설치할 필요가 없습니다. EXE에는 Python, Tk, openpyxl과 상단 Lotto 이미지가 포함됩니다. 전자서명은 적용하지 않았습니다.

## 사용 방법

1. 기존 `Donghaeng_Lotto.xlsx` 또는 포함된 빈 양식에 최소 412회의 데이터를 준비합니다.
2. **Select Input File**로 `.xlsx` 파일을 선택합니다.
3. **분석 후 10세트 추출**을 누르면 중앙 오른쪽 추첨기에서 공이 섞이고 배출되며, 왼쪽 SET 1~10의 번호가 하나씩 공개됩니다. 고·중·저 내부 세부 빈도 구성까지 적용한 조합입니다.
4. 연출이 끝나면 **추천 10세트 엑셀 저장**으로 추천 번호, 구성 비율, 빈도 그룹, 분석 범위·대상 회차를 저장할 수 있습니다.
5. 다음 주에는 새 회차의 Draw, Draw date, 본번호 6개를 행으로 추가해 저장한 후 파일을 다시 선택하세요.

파일에 들어 있는 **모든 회차**를 분석합니다. 836~1247회(412회)에서 1248회를 추가하면 **836~1248회 전체 413회**로 1249회를 추천합니다. 오래된 데이터를 지우거나 고정 길이로 자르지 않습니다.

한 번 생성한 10세트는 **반복 클릭해도 유지**합니다. **Select Input File로 파일을 다시 선택하면 동일 가중치 번호를 새로 무작위 선택**합니다. 새로 추첨해도 우연히 같은 번호가 나올 수 있습니다. 각 세트는 중복 없는 6개 번호이며, 10세트는 서로 다른 조합입니다. 세트 사이에는 번호가 겹칠 수 있습니다. 데이터가 추가되더라도 순위가 유지되면 추천이 같을 수 있습니다.

GUI 제목은 `Lotto Generator`이며 입력 원본 표와 번호별 통계 표는 표시하지 않습니다. 선택 파일명, 처리 상태, 추천 10세트와 그 아래 작은 글씨의 빈도 그룹 번호를 보여줍니다. 각 고·중·저빈도 그룹 내 최고 가중치 번호는 검정색 볼드체로 표시합니다. 최고 가중치 동률은 모두 강조하며 나머지는 회색입니다. 이 강조는 세트 포함 여부나 실제 당첨 확률의 우위를 뜻하지 않습니다. 그룹 번호는 파일 선택 직후 가중치 내림차순으로 표시하며 `|`로 세부 상·중·하 5개씩을 구분합니다. 영문 UI 폰트는 Times New Roman이며 오른쪽 아래에 `Hun-Kee, Lee All rights Reserved.`를 표시합니다.

## 추첨 방송 스타일 애니메이션

3차원 좌표·구형 경계 반사·카메라 회전·원근 투영을 계산해 Tk Canvas에 그리는 소프트웨어 3D 애니메이션입니다. 앞뒤 깊이에 따라 공 크기와 가림 순서를 조절하며 구면 음영과 하이라이트를 표시합니다. OpenGL이나 별도 GPU 라이브러리가 필요하지 않습니다. 중앙 오른쪽 원형 추첨기에서 공이 회전·혼합되고, 선택된 번호 공이 아래로 배출됩니다. 각 세트 안의 번호는 숫자 크기가 아니라 베이지안 가중치가 높은 순서로 공개합니다. 왼쪽은 SET 1의 6개부터 SET 10의 6개까지 총 60개 번호를 순서대로 공개합니다. 전체 연출은 약 31초이며 **즉시 표시**로 기다림 없이 결과를 표시할 수 있습니다.

결과는 기존 베이지안 모델·빈도별 세부 비율·동일 가중치 무작위 선택으로 먼저 계산합니다. 애니메이션은 그 결과를 보여주는 연출이며 공의 움직임이 실제 추천 번호를 결정하지 않습니다. 연출용 난수도 추천 계산과 별도로 관리합니다. 결과와 색상은 기존 번호 구간 규칙을 따르며 영상 재생용 패키지나 인터넷은 필요 없습니다.

연출 중에는 중복 추출과 결과 저장을 막습니다. 파일을 새로 선택하면 기존 연출과 결과를 취소합니다. 완료 후 반복 클릭은 결과를 유지하고 파일 재선택 시 동률 번호를 다시 추첨합니다.

## 엑셀 입력 형식

`Lotto Draws` 시트가 있으면 해당 시트를 읽고, 없으면 활성 시트를 읽습니다. 아래 8열 형식을 권장합니다.

| Draw | Draw date | N1 | N2 | N3 | N4 | N5 | N6 |
|---|---|---|---|---|---|---|---|
| 회차 | 추첨일 | 본번호1 | 본번호2 | 본번호3 | 본번호4 | 본번호5 | 본번호6 |

헤더 대소문자는 구분하지 않습니다. 번호는 정수 셀로 입력하고 보너스 번호·추가 열·수식은 제외하세요. 날짜는 Excel 날짜 셀이나 `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD` 텍스트를 지원합니다.

입력 데이터 전체의 회차 중복·누락, 추첨일 순서, 번호 범위(1~45), 회차 내 번호 중복, 빈 셀 등을 검사합니다. 행 순서는 무관하며 회차 기준으로 정렬합니다. 최소 412회가 필요합니다. 이전 7열(회차 + 본번호)과 6열(본번호만) 입력도 전체 행을 사용하지만, 누락된 회차·날짜 정보는 표시할 수 없습니다.

다음 대상 회차는 입력의 최대 회차 + 1이며 추첨 예정일은 최신 입력 날짜 + 7일입니다. 공식 일정 자동 조회는 하지 않습니다. 원본 엑셀 파일은 수정하지 않으며 데이터는 외부로 전송하지 않습니다. `.xls`와 암호화 파일은 지원하지 않습니다. 첨부된 원본 데이터는 배포하지 않습니다.

## 빈도 그룹과 10세트 구성

전체 입력 회차의 번호별 출현 횟수를 내림차순으로 정렬해 **고빈도(1~15위), 중빈도(16~30위), 저빈도(31~45위)** 각 15개로 분류합니다. 출현 횟수가 같으면 번호 오름차순으로 구분합니다. 따라서 경계에서 횟수가 같은 번호가 서로 다른 그룹으로 나뉠 수 있습니다. 새 회차를 추가하면 전체 데이터 기준으로 다시 분류합니다.

| 세트 | 고빈도 | 중빈도 | 저빈도 |
|---|---|---|---|
| SET 1~4 | 2 | 2 | 2 |
| SET 5~8 | 3 | 1 | 2 |
| SET 9~10 | 2 | 1 | 3 |

각 세트에는 서로 다른 번호 6개가 들어갑니다. 같은 비율의 두 세트도 서로 다른 조합이며 세트 간 번호 중복은 허용합니다. GUI에서 SET 옆에 고:중:저 구성 비율을 표시합니다. 각 15개 그룹을 다시 베이지안 가중치 내림차순(동률은 번호 오름차순)으로 정렬해 **내부 상위·중위·하위 각 5개**로 나눕니다. 같은 사전 강도를 쓰므로 가중치 순서는 출현 횟수 순서와 같습니다.

아래 표에서 각 셀은 해당 부모 그룹 안의 `상위:중위:하위` 선택 개수입니다.

| 세트 | 고빈도 내부 | 중빈도 내부 | 저빈도 내부 |
|---|---|---|---|
| SET 1~2 | 0:1:1 | 0:1:1 | 0:1:1 |
| SET 3~4 | 1:0:1 | 1:0:1 | 0:1:1 |
| SET 5~6 | 0:2:1 | 0:0:1 | 1:1:0 |
| SET 7~8 | 1:1:1 | 0:1:0 | 1:0:1 |
| SET 9~10 | 1:1:0 | 0:0:1 | 1:1:1 |

기존 5가지 세부 구성에서 각각 조건을 만족하는 모델 순위 상위 2개씩, 총 10개 조합을 선택합니다. 각 세트는 지정된 9개 세부 그룹의 개수를 정확히 충족합니다. 추출 시 세부 그룹 안에서 가중치가 같은 번호는 무작위로 선택하며, 작은 번호를 우선하지 않습니다. 예를 들어 4·20·40이 같은 최고 가중치라면 세 번호 중에서 무작위로 선택합니다. 10개 조합 자체는 서로 다르며 세트 사이에 같은 번호가 다시 나오는 것은 허용합니다. 파일 입력 후 세트 아래에 고·중·저빈도 번호 15개씩이 가중치 높은 순으로 작게 표시됩니다. 엑셀의 `추천번호` 시트에 세부 비율도 저장하며, `빈도그룹` 시트에는 부모 그룹·세부 그룹·번호·출현 횟수·가중치를 저장합니다.

## 세트별 번호 패턴 제한과 공개 순서

- 연속된 번호 3개 `n, n+1, n+2`는 금지합니다. `1,2`는 허용하고 `1,2,3`은 제외합니다.
- 7씩 연속 증가하는 번호 3개 `n, n+7, n+14`는 금지합니다. `1,8`은 허용하고 `1,8,15`는 제외합니다.
- 위 패턴은 정렬 순서나 화면 표시 위치와 관계없이 세트 전체에서 검사합니다. 서로 떨어진 쌍 여러 개는 허용합니다. 예를 들어 `1,2`와 `10,11`이 함께 있어도 되고, `1,8,22`처럼 연속된 7 간격 삼중항이 아닌 조합도 허용합니다.
- 각 세트는 가중치 내림차순으로 공개하고 같은 순서로 엑셀에 저장합니다. 동률 후보의 선택은 무작위이며, 선택 후 표시 순서의 동률은 번호 오름차순입니다.

## 베이지안 가중치와 구성별 순위

번호 i의 포함확률에 `Beta(s × 6/45, s × 39/45)` 사전분포를 둡니다. 사전 강도 s는 412로 고정하며 가상의 균등 추첨 412회를 의미합니다. **실제 분석 회차 수는 입력 전체 N회**입니다.

N회 중 c_i회 출현한 번호의 사후 평균 가중치는 `(s × 6/45 + c_i)/(s + N)`입니다. 번호별 Beta–Binomial은 주변확률 추정이며 번호 간 독립 사후근사를 사용합니다.

베이지안 가중치를 이용한 순차 비복원추출(Plackett–Luce) 모델에서 각 6개 조합의 720가지 선택 순서 확률을 부분집합 동적계획법으로 합산합니다. 그룹 안에서의 가중치 단조성을 이용한 우선순위 탐색으로 **요청된 구성별 상위 조합**을 선택합니다. 각 세부 구성과 번호 패턴 제한을 모두 만족하는 후보 중 모델 확률이 높은 조합 2개씩을 계산합니다. 금지 패턴에 해당하는 상위 후보를 건너뛰고 하위 후보도 계속 탐색합니다. 조건을 만족하는 후보가 부족하면 제한을 풀지 않고 오류를 표시합니다. 구성 비율 자체는 사용자가 지정한 규칙이며 전체 조합을 통틀어 확률이 높은 10개를 선택하는 방식은 아닙니다.

서로 다른 가중치의 우선순위는 유지하고, 같은 세부 그룹에서 동일 가중치인 후보들끼리만 Python SystemRandom으로 순서를 섞어 선택합니다. 전체 번호를 무작위 추출하거나 가중치를 샘플링하지 않습니다. 파일 선택 상태에서는 생성 결과를 보관하며 파일 재선택 시 새로 추첨합니다. 그룹 경계와 목록 표시에서의 동률 순서는 기존 번호 오름차순으로 유지하므로, 추첨할 때도 그룹의 소속과 구성 비율은 바뀌지 않습니다. 빈도 그룹과 구성 비율은 과거 데이터에 대한 분류·선택 규칙이며 당첨 확률 향상이 입증된 것은 아닙니다. 공정하고 독립적인 로또에서는 모든 조합의 1등 확률이 1/8,145,060입니다. 과거 결과를 이용한 모델 성능 백테스트는 수행하지 않았습니다.

## 개발 및 검증

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python lotto_gui.py
```

Windows에서 재빌드:

```text
python -m pip install -r requirements-build.txt
python build_exe.py
```

결과는 `dist/Lotto Generator.exe`입니다. 소스 실행에는 Python 3.10 이상과 Tcl/Tk가 필요합니다.

모델·엑셀 테스트 28개가 통과했습니다. 전체 413회 반영, 반복 클릭 시 결과 보관과 파일 재선택 시 새 추첨, 동일 가중치 무작위 선택, 중복 없는 10개 조합, 부분집합 확률과 720개 순서 확률의 일치, 빈도별 세트 구성, 그룹별 동률 처리, 9개 세부 그룹의 정확한 선택 개수, 작은 후보군 전수 계산과 구성별 상위 순위의 일치 등을 확인합니다. GUI 통합 검사에서는 60개 번호의 순차 공개, 중복 클릭 방지, 즉시 표시, 새 파일 입력 시 연출 취소, 추첨기 타이머 종료도 검증합니다. 순위 탐색이 금지 후보를 건너뛰어 올바른 상위 후보를 찾는지 전수 계산과 비교하고, 3D 원근 투영·회전 거리 보존·구형 경계 반사도 확인합니다. Wine 10에서 Windows Python GUI의 파일 읽기·추천·저장과 배포 EXE의 창 실행·정상 종료를 검증합니다. 실제 Windows PC에서의 검증은 아직 수행하지 않았습니다.
